## Background and implementation records

These records are not an automatically current feature list. Read each date,
branch, and acceptance status together with current code.

- [Product foundation](PRODUCT_FOUNDATION.md): human-judging and evidence
  principles, with an August 2026 roadmap that has since progressed.
- [Original vision](VISION.md) and [progress log](../PROGRESS.md): historical
  intent and checkpoint-specific implementation and validation.
- [Roster onboarding](ROSTER_ONBOARDING_V2.md) and [Template V7](PARTICIPANT_TEMPLATE_V7_FINAL_PLAN.md):
  draft safety, spreadsheet compatibility, and later workbook direction.
- [Question preparation](QUESTION_BANK_PREPARATION_PLAN.md) and
  [question focus](QUESTION_FOCUS_IMPLEMENTATION.md): preparation and saved evidence.
- [Fixed Mushaf integration](FIXED_REPLAY_INTEGRATION_CHECKPOINT.md) and
  [offline default](MUSHAF_OFFLINE_DEFAULT_CHECKPOINT_2026-09-10.md): integration
  milestones and validation limits.
- [Results safety](RESULTS_SAFETY_PREPLAN.md),
  [participant evidence](PARTICIPANT_RECITATION_EVIDENCE_IMPLEMENTATION_PLAN.md),
  and [word replay](WORD_FIRST_REPLAY_IMPLEMENTATION_PLAN.md): review/replay
  contracts; proposals are not proof of implementation or approval.

Other dated plan, research, checkpoint, and QA files preserve the development
record. Root `KIMI_TASK_*` files are archived handoffs, not current instructions.
New work follows the working agreement and current source.
